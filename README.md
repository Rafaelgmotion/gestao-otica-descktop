# Aplicativo de Gestão para Óticas

Sistema desktop para gerenciamento de óticas, desenvolvido com React e Tauri, com funcionamento independente e offline.

## Estrutura do repositório

```text
app-otica/
├── app-otica-ubuntu/
│   └── Versão para Linux Ubuntu
├── app-otica-wind/
│   └── Versão para Windows
└── README.md
```

## Instalação e utilização

### 1. Ubuntu / Linux

Acesse a pasta `app-otica-ubuntu` e localize o executável ou instalador correspondente ao Linux.

Execute o arquivo para instalar ou iniciar o aplicativo, conforme o formato disponibilizado.

### 2. Windows

Acesse a pasta `app-otica-wind` e localize o instalador `.exe`.

Execute o instalador e siga as instruções apresentadas.

## Dependências

Para instalar as dependências do projeto, quando necessário:

```bash
npm install
```

**Observação:** para utilizar as versões já compiladas, não é necessário instalar Node.js, npm ou executar comandos de desenvolvimento.

## Banco de dados

O aplicativo possui armazenamento local próprio.

- O banco de dados é criado automaticamente durante a instalação ou primeira execução.
- Os dados ficam armazenados localmente no computador.
- Não depende de servidor externo.
- Não exige conexão com a internet.
- Cada instalação mantém seus próprios dados.

## Funcionamento

O aplicativo foi desenvolvido para funcionar de maneira independente em cada computador.

As versões Ubuntu e Windows são distribuídas separadamente, respeitando as particularidades de cada sistema operacional.

## Tecnologias

- React
- Tauri
- JavaScript
- Banco de dados local
